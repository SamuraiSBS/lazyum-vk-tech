# DEP-09 — immutable release candidate

Дата фиксации и обновления: 2026-09-28. Pinned source candidate и архив на `D:` проверены; цикл 8 подтвердил локальную сборку и digest образа. Хронология: цикл 2 stdin-передача архива завершилась ошибкой `Канал был закрыт.`, а последующая проверка Docker API получила `permission denied`. В цикле 5 сборка из распакованного D: архива была отменена после 16m36s; тогда unified session вернула `1`, но это не native Buildx exit code и образ не инспектировали. В цикле 8 Buildx history и полный лог восстановили фактический статус той попытки (`Canceled`) и шаги, после чего была выполнена одна явно разрешённая повторная сборка с `desktop-linux`: она завершилась с exit `0`, `18/18` шагов, и локальный образ был проверен через `docker image inspect`. Контейнерный smoke подтвердил health и readiness внутри контейнера с временной demo-auth конфигурацией; host-side port forwarding smoke не прошёл (`curl` exit `7`), поэтому доступность через порт хоста не подтверждена. Без demo-auth переменных readiness ожидаемо вернул `503`; для запуска нужно задать `VK_HACKATHON_DEMO_AUTH_USER` и `VK_HACKATHON_DEMO_AUTH_PASSWORD` без записи значений в этот отчёт. Package test suite не запускался. Нет push в registry, staging/production/cloud deploy, публичного GO или оценки качества презентаций.

## Rebuild procedure

Run from a clean PowerShell session. The archive restricts the build context to the pinned Git tree and the local PPTX dependency; it excludes current dirty/runtime files. Use a unique local tag containing the candidate SHA and record the resulting image digest separately.

```powershell
$sourceSha = 'd1aaa38c1359867fb8c6eb99e130596eae4bba63'
$archive = Join-Path $env:TEMP "vk-hackathon-$sourceSha.tar"
$context = Join-Path $env:TEMP ("vk-hackathon-$sourceSha-" + [guid]::NewGuid().ToString('N'))
git -c safe.directory=D:/presentation archive --format=tar --output=$archive $sourceSha packages/pptxgenjs vk-tech-hackathon
New-Item -ItemType Directory $context | Out-Null
tar.exe -xf $archive -C $context
docker.exe buildx build --load --platform linux/amd64 --progress=plain --tag "vk-hackathon:$($sourceSha.Substring(0,12))-local" --file (Join-Path $context 'vk-tech-hackathon\Dockerfile') $context
```

The same command rebuilds this SHA from a fresh archive. `Dockerfile.dockerignore` pins build-context exclusions; Dockerfile arguments pin Node and Debian snapshot versions. An optional public npm cache seed may be supplied through the existing BuildKit `npm-cache-seed` context. Do not reuse a mutable checkout as the build context.
